The documents the project was built from.

| Path | What's in it |
|---|---|
| [`constitution.md`](constitution.md) | The short list of rules the project is built on |
| [`roadmap/`](roadmap/) | Phases in dependency order, each with exit criteria |
| [`specs/`](specs/) | Feature specifications, each with a status |
| [`decisions/`](decisions/) | Architecture decision records, including open questions |

## About references to removed files

While the project was built it also kept review records, security audits, test
plans, document templates, task lists, and agent instruction files. Those were
removed from the tree after the 1.0.1 release. Documents here still mention them
by name (for example "audit 0012" or `tasks/todo-phase13-network.md`); those
mentions are historical. The files are in the git history, and the tree at the
[`v1.0.1` tag](https://github.com/Alexandryn/alexandryn/tree/v1.0.1) still has them.
