# Phase 06 — Library

*Outline — expanded to a full phase document when phases 03 and 04 close.*

|---|---|

## Objective

The first real vertical slice: browse, search, filter, sort, and manage
collections against the phase 03 backend and phase 02 domain model, over
locally stored records only. Proves the domain and backend foundation stand
on their own before any external integration exists.

## Scope

**In**

- Library home, work detail, collections index and collection detail
  screens, wired to the real backend
- Search, filter, sort, and grid/list view over local data
- Collection create/edit/membership
- The first real frontend/backend contract exercised end to end

**Out**

- Open Library — phase 07. Remote sources — phase 08. Import — phase 10.
  Reading — phase 11.

## Exit criteria

- [ ] Browse, search, filter, sort functional against real local data
- [ ] Work detail and collection management functional
- [ ] Responsive across desktop, tablet, mobile layouts
- [ ] Test coverage across unit, integration, and E2E for this slice
- [ ] Maintainer approval recorded
