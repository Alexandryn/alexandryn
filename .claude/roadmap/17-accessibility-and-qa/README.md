## Objective

Conformance testing and the full regression matrix that per-phase
accessibility work doesn't cover on its own: WCAG 2.1 AA across the whole
app, cross-device/cross-browser QA, and performance at scale.

## Scope

**In**

- WCAG 2.1 AA audit across all screens
- Cross-device/cross-browser test matrix
- Performance benchmarks at large-library scale (10k+ items)

**Out**

- New features — this phase is verification only.

## Exit criteria

- [ ] WCAG 2.1 AA criteria met, automated and manual
- [ ] Full keyboard operability across 100% of flows
- [ ] QA matrix executed across all target platforms and viewports
- [ ] Large-library performance benchmarks met
- [ ] Maintainer approval recorded
